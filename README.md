Аналіз результатів

Insertion Sort добре працює лише на малих або майже відсортованих масивах. Його головний недолік — квадратична складність O(n²). Це означає, що при збільшенні кількості елементів час виконання зростає дуже швидко.

Merge Sort працює значно стабільніше. Його складність у більшості випадків становить O(n log n), тому він краще підходить для великих масивів. Merge Sort повільніша за вбудоване сортування.

Timsort показує найкращі результати. Він використовується у вбудованих функціях Python sorted() і .sort(). Його перевага в тому, що він поєднує ідеї сортування злиттям і сортування вставками. Якщо дані вже частково відсортовані, Timsort використовує це і працює ще швидше.

Висновок

Емпіричне тестування підтверджує теоретичні оцінки складності алгоритмів. Insertion Sort є простим, але неефективним для великих масивів. Merge Sort значно ефективніший, але потребує додаткової пам’яті та поступається оптимізованому вбудованому сортуванню Python.

Найкращим варіантом у більшості практичних задач є Timsort, який використовується у sorted() та .sort().
